# 数据处理工具箱

## 数据源

1. 数据类型有字符（string）、数字（number）、布尔值（boolean）、数组（array）、对象（object）;
2. 选择字符串通过文本框输入，无字数限制（除正常文字、日期、还可能包含特殊字符、json字段）;
3. 选择数字通过数字输入框输入，无小数位限制;
4. 选择布尔值通过复选框选择;
5. 选择数组会有两种方式填写，一种是导入excel文件，另一种是填写json输入框;
6. 选择对象通过json输入框填写;
7. 通过接口获取数据，填写接口链接，请求头，请求参数，请求类型；

## 数据处理

1. 对不同类型的数据源进行处理，包括字符串、数字、数组、对象、时间;
2. 字符串处理：支持trim、toLowerCase、toUpperCase、replace、substring等操作;
3. 数字处理：支持加减乘除、取整、取余等操作;
4. 数组处理：支持删除、排序、去重等操作;
5. 对象处理：支持删除、修改、查询等操作;
6. 时间处理：支持格式化、解析、加减等操作;
7. 可以写函数块，支持自定义处理逻辑;
8. 点击这些方法还可以看代码块；
9. 组合处理：可以将多个处理步骤组合起来，形成一个处理链;
10. 包含处理：可以在处理链中包含其他处理步骤，实现更复杂的处理逻辑;

## 处理结果

1. 展示处理结果；
2. 导出处理结果；
3. 转成json展示；
